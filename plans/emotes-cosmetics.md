# LC emotes and MoreCompany cosmetics: implementation plan

> **Moved 2026-11-16:** the `.temp/alterum/` layout referenced below is history — the mod tree is now `alterum/tracks/<track>/mod/` and its payload `~/assets/monorepo/alterum-data/tracks/<track>/mod/`, outside the repo; kept as written.

## Decisions and implementation seams
- Port the actual BetterEmotes motion data through a CPU pose player; native Alterum gestures are a disposable plumbing test, never the deliverable. Do not port LC's controller or construct non-Legacy clips with runtime `SetCurve`.
- Rebuild all 21 MoreCompany cosmetics from extracted geometry/textures. Hats must render in the existing mirror and in eligible screen views; hiding them from the mirror is a regression.
- Keep both features local-only in this increment: affect the owner's third-person model on this client; do not alter remote bodies, RPCs, appearance registries, or first-person arms. Other clients see their ordinary unmodified representation of this player.
- Add hot-owned `PortAssetStore`, `EmotePlayer`, `CosmeticsRuntime`. Keep the external interfaces small: load/resolve assets; `Start(id)/Stop(reason)/PostAnimationUpdate()/Dispose()`; `Equip(ids)/ApplyScreenVisibility()/BeginMirrorView(camera)/Dispose()`. Hide decoding, fitting, arbitration and renderer bookkeeping inside these modules.
- Work under `.temp/alterum/mod/`; place offline tooling under `.temp/alterum/tools/ports/`. No original-bundle loading in the game, header spoofing, new animation jobs, or importing LC MonoBehaviours.

## Shared data, host configuration and restart boundary
- Ship `ports.apack` as a ZIP beside the host assembly, not an embedded resource: versioned `manifest.json`, little-endian f32/u32 buffers, RGBA8 textures, source/reference rigs and audit JSON. Resolve from the host assembly directory, never process CWD. Keep emotes/cosmetics in separate ZIP namespaces so either can be replaced independently.
- Manifest must include schema version, source bundle SHA256/object pathID, asset id, lengths/counts, bounds, coordinate/row conventions, dependency ids, and per-entry checksums. Decode/decompress/validate managed arrays off-thread; construct/destroy Unity objects only on the main thread. Enforce maximum dimensions/counts/ZIP expansion and reject NaNs, invalid indices and duplicate ids.
- In host `Plugin.cs` bind `[Ports] PackFile=ports.apack`; `[Emotes] Enabled=false, Selected=Clap, ToggleBinding=<Keyboard>/f6, FadeSeconds=0.2, StopSpeed=0.1`; `[Cosmetics] Enabled=false, Equipped=, ToggleMenuBinding=<Keyboard>/f7, FitScale=1`. Pass corresponding primitive/string fields through `ConfigSnapshot`; clamp fade to 0–1 s, speed to >=0, fit scale to 0.25–4.
- Add host-owned persistent `CosmeticTag : MonoBehaviour`, registered once with `ClassInjector.RegisterTypeInIl2Cpp<CosmeticTag>()` and the `IntPtr` constructor. The marker is an empty public type in the stable host (add a hot-project reference to that assembly, not a host reference to Hot), never an owner of hot state; add it to each cosmetic renderer GameObject before parenting beneath the player. Do not inject a hot-assembly type on each reload.
- Add `IHotModule.PostAnimationUpdate()` and host forwarding for it; add `IHostContext.SetCosmeticsEquipped(string csv)` so the hot OnGUI selector persists through host `ConfigEntry.Value` + config save. Batch these Contracts/host changes with the snapshot additions: **one game restart is unavoidable**, not solvable by hot reload. Subsequent hot/data-only changes remain reloadable.
- Host installs one generated-interop `PlayerLoopSystem.UpdateFunction` callback immediately after `PreLateUpdate.ScriptRunBehaviourLateUpdate`, before `PostLateUpdate.UpdateAllRenderers`; retain its delegate and remove only this callback on teardown. Forward to the current hot module, never retain an unloaded module. Use the shipped CoreModule delegate wrapper/conversion, not an assumed new AOT generic specialization.
- Move manual mirror `Tick()` from ordinary `ModelSwapRuntime.LateUpdate()` into the end of `PostAnimationUpdate()`, after emote pose writes and cosmetic screen-state updates. This gives both the manually rendered mirror and normal cameras the final pose. Keep ordinary LateUpdate bookkeeping; do not invoke the entire runtime twice.

## Emotes: offline decoding and hash recovery
1. Pin UnityPy 1.25.4. Load `tracks/emotes/ref/unz/BepInEx/plugins/BetterEmotes/animationsbundle` and dependencies; enumerate all 12 clips, not the controller bundle's locomotion. Export ids/names, frame rate, start/stop, loop flags, binding counts, stream counts and root settings. Export no executable AnimationEvents. Preserve Sign/D_Sign as motion; LC text-entry/prop logic and clap audio are not prerequisites for this motion port.
2. Read `m_ClipBindingConstant.genericBindings`: retain `(path, attribute, typeID/classID, customType, script, isPPtrCurve, isIntCurve)` and compute each binding's scalar range in serialized order. `path` is the CRC32 pathHash; `attribute` is the attribute id/hash, **not always a CRC of a property name**. Transform classID 4 uses 1=position xyz, 2=quaternion xyzw, 3=scale xyz, 4=Euler xyz; ordinary scalar/component bindings consume one channel. Separate PPtr curves from numeric streams.
3. Build-time optimized clips usually contain hashes, not recoverable path strings; do not trust scrubbed `.anim` paths such as `path_0x...` as bone names. Extract the LC metarig Transform tree/reference TRS from MoreCompany's display model bundle and BetterEmotes' available skeleton/prefab data; inspect Avatar/TOS path tables too. Extract Alterum's target reference hierarchy/TRS from its model assets offline, not from an arbitrary moving pose.
4. Generate slash-separated paths relative to every plausible animation root in both rigs, including metarig wrappers, the empty path and all descendants. Hash exact case-sensitive UTF-8 bytes, with `/`, no leading slash, terminator or case folding. Unity's path CRC here is CRC-32/ISO-HDLC (IEEE reflected polynomial 0xEDB88320, init 0xFFFFFFFF, xorout 0xFFFFFFFF, refin/refout true); Python `zlib.crc32(path.encode('utf-8')) & 0xffffffff` computes it.
5. Assert the existing source fixtures before decoding: `spine=2463100623`, `spine/spine.001=254801669`, `spine/spine.001/spine.002=4095213152`, `spine/spine.001/spine.002/spine.003=674009458`, `spine/thigh.L=49267413`, `spine/thigh.R=4175495094`. Match all animated Transform path hashes to candidates; reject collisions/ambiguity rather than guessing. A later diagnostic may compare `Animator.StringToHash(path)` cast to uint; this is a verification, not a running-game dependency of extraction.
6. Read ordinary `m_PositionCurves`, `m_RotationCurves`, `m_EulerCurves`, `m_ScaleCurves`, `m_FloatCurves`, and compressed quaternion curves when populated. For optimized clips follow `m_MuscleClip.m_Clip`'s OffsetPtr payload into `m_StreamedClip`, `m_DenseClip`, `m_ConstantClip`; a field named MuscleClip does not imply Humanoid. Port the version-aware AssetStudio decoder logic, not just UnityPy object enumeration [1].
7. Reinterpret streamed `data` uint32 words as little-endian bytes. Decode each frame's float time/int keyCount, then each key's int scalar index/four float cubic coefficients; evaluate its segment polynomial, retaining previous keys for channels absent from a frame. Reproduce AssetStudio's tangent/step reconstruction, sentinel frames and time handling; do not linearly interpolate streamed key values. Dense samples are frame-major at `m_BeginTime + frame/m_SampleRate`, stride `m_CurveCount`; constant values hold over the full clip.
8. Numeric scalar space is streamed indices first (`curveCount`), then dense, then constant; map that flattened index through the width-aware binding ranges. Check total widths against stream counts and handle any version-specific discrete/int partitions explicitly. Do not reset vector component indexing at a stream boundary. Preserve source reference/default values for genuinely absent channels; never replace undecoded data with zero.
9. Bake evaluated source local TRS at 60 Hz plus the exact final sample, normalized quaternion xyzw and sign continuity (`dot(previous,q)<0 => -q`); preserve source start-time offset and explicit end/loop policy. Store duration/sample count, channel-presence masks, full reference skeleton, original bindings and decoded keys for audit. Test first/middle/final poses and dense/constant-only and mixed-stream fixtures before runtime work.
10. Require every animated binding to be classified: supported transform, explicitly ignored material/object property, or unsupported error. Animator classID 95/body/muscle bindings must trigger `EMOTE_UNSUPPORTED_HUMANOID`, not become Transform tracks or guessed muscle indices. These LC clips are Generic; if an exception is discovered, route that clip through the editor fallback only after recording the proof. UnityPy is not a Humanoid solver.

## Emotes: semantic retargeting, ownership and sampling
- Resolve source path to semantic bone, then semantic bone to a cached target Transform; never substitute target hashes for source hashes in the compiled blob. Map LC `spine` to target `pelvis`, `spine.001/.002/.003` to same-named target torso bones, `arm.L_upper/lower` to `upper_arm.L/forearm.L` (and R), and LC `spine.004` **to target `head`**, not target `spine.004` merely because names match. Use explicit left/right aliases and verify parent/child semantics.
- Evaluate source global rotations in model space from its full reference hierarchy. For matched bone b let `D = RsAnimated(b) * inverse(RsRest(b))`; with calibrated source-model-to-target-model basis C, set `RtDesired(b) = C * D * inverse(C) * RtRest(b)`. Traverse target parents first and derive local rotation as `inverse(RtDesired(parent))*RtDesired(b)`. Unmatched target bones retain reference local rotation and inherit the parent's motion. This handles changed path depth/rest axes without naïve local quaternion copying.
- Define C from reference pelvis-up/forward and left-right axes, not a fitted per-frame rotation. Keep target local translations/bone lengths and local scales by default; do not copy source limb lengths or animated scale onto the player. Preserve target-only toe/spine spacer/end bones at reference local TRS; report source-only fingers/twist/end bones as unmapped. Missing target fingers mean reduced Middle_Finger fidelity, explicitly reported, not a replacement native clip. Missing major pelvis/spine/head/limb mappings fail that model's binding.
- Apply source pelvis positional delta relative to source rest, converted by C and target/source reference leg-length ratio, to target pelvis; remove horizontal net trajectory and initial offset for in-place playback, retain vertical bob. Do not move the physics/network player root, apply LC locomotion multipliers or consume root motion. Store discarded root channels for audit. Unexpected non-root position/scale animation is a classified per-clip exception: retain in audit and flag fidelity loss rather than silently distorting target proportions.
- Runtime samples adjacent baked source frames at scaled game time using `Vector3.Lerp` and shortest-arc `Quaternion.Slerp`, evaluates the retarget above and writes only owned target local transforms using `Transform.SetLocalPositionAndRotation(p,q)` plus `localScale`. Cache arrays/maps; no LINQ, hierarchy scans or allocations per frame. Pausing the game pauses emote time; camera rendering never advances it.
- Resolve only the local owner: `Player.GetRefs<PlayerModelReferences>().ThirdPlayerModelPersonAnimancerController.CurrentPersonAnimancerComponent`. Cache the controller/model generation, `DoingSomethingHandler`, state-machine reference and target neutral rig. Rebind after `PlayerModelSetuper.SetupModel`/deinitialization; dispose the old player before touching the replacement skeleton.
- Enter only while grounded/alive, no movement input, no incompatible item/interaction/cutscene/busy state, and `IsAnimancerAndAnimatorEnabled`. Create one unique native `Il2CppSystem.Object` lease key; capture current displayed bone TRS; call `DoingSomethingHandler.StartDoingSomething(key)` and controller `DisableAnimancerAndAnimator(key)`. Do not globally disable a shared Animator or mutate runtimeAnimatorController. ASMC is unavailable while this pair is disabled; do not build a fake authored `DoingSomethingASMC` asset.
- Observe `ASMCConditionState` transitions model-locally and patch the local handler's `StartDoingSomething/StopDoingSomething` entry points to distinguish native key pointers: ignore our key, record foreign keys, and cancel on any foreign acquisition. Entry is allowed to cause its own busy transition; any subsequent conflicting/high-priority transition cancels. Never suppress another system's disable key. Verify controller disable actually suspends Animator/Animancer evaluation; if it does not, log ownership failure and stop instead of fighting it every frame.
- Write poses in the host post-animation callback after all MonoBehaviour LateUpdates, Animator evaluation/IK and ASMC LateUpdate, then render the mirror. A plain Pump LateUpdate has no ordering guarantee. During acceptance compare owned transforms immediately before normal rendering against the just-written pose; a later writer produces `EMOTE_LATE_WRITER` and blocks release until that specific writer is ordered before this callback. Reapply cached pose before mirror render if needed, never resample/advance twice.
- Fade in over configured 0.2 s from captured entry pose to moving emote pose. Normal stop/end: capture the final displayed pose, release only our disable lease with the shipped typo `EnabledAnimancerAndAnimator(key)` and `StopDoingSomething(key)`, then blend final pose toward each frame's freshly evaluated live game pose in the post-animation callback over 0.2 s. Do not blend out toward the stale entry pose; an already-held foreign disable key stays held.
- Use movement input magnitude >0.1 or horizontal speed >configured StopSpeed to cancel in Update before the next movement animation. Same-key toggles stop; switching clips keeps ownership and crossfades from current pose. Nonlooping clips stop at source end; loops use source loop metadata, including a validated seam. Death, model destruction, hot unload, external animation disable or priority interaction release immediately (no cosmetic pose hold during a kill/cutscene). Cleanup must run on all exceptions and Dispose.
- Play only on third-person bones. Do not force-enable the owner's body or change camera mode: `MirrorPlayerVisibility` already isolates it, and the mirror is the guaranteed observation surface even in first person. Leave first-person hands untouched; remote players remain on their native animation on every client. Do not claim multiplayer emote synchronization.

## Cosmetics: extraction, fitting and runtime reconstruction
1. Enumerate prefabs carrying `CosmeticInstance` in `tracks/cosmetics/unpack_bundle_3110260`; require 21 ids: 18 HAT, CHEST outoforder, HIP gunholster, R_LOWER_ARM watch. Follow all mesh/material/texture PPtrs, including external resource streams. Preserve every renderer/submesh/material slot, not one mesh per cosmetic; deduplicate shared buffers by hash.
2. Drop prefab root authoring-scene position/rotation, record its scale separately, and export the complete descendant TRS chain, retaining nonuniform scales and rotations. Party hat must retain `Party_Hat` y=1.3932, z=-0.064, scale=0.43 and its Cone/Sphere transforms; do not replace them with a guessed single offset. Record prefab id/type/icon and the source attachment semantic bone.
3. Export positions, normals, tangents, colors, all used UV channels, submesh triangle lists with baseVertex already resolved, material slots and bounds in Unity's original handedness. Decode all vertex formats/compressed mesh buffers; validate winding with a checker. No skinned cosmetics are expected; if encountered, bake reference skinning into static mesh space before export. Preserve propeller/eyeball child hierarchy and port the two Generic child animations through the same numeric sampler; replace EyeballShaderGraph with its base texture/color, not HDRP shader code.
4. Decode textures offline to uncompressed RGBA8 mip 0; specify row orientation, sRGB/data intent, wrap/filter modes and UV tiling/offset in manifest. Decode HDRP normals/swizzles before export; repack masks to URP metallic R/smoothness A and separate occlusion G. Unsupported detail/subsurface effects are intentionally omitted with a material-conversion report.
5. Add per-cosmetic fit metadata offline: source socket coordinate frame, a feature anchor (brim/contact plane for hats, face plane for glasses/masks; torso/hip/forearm surface for other types), and width of the reference anatomy. Derive anatomical dimensions from source and target reference meshes (head-weighted vertices/bindposes, not whole-body bounds); save per-target-model fit records. Start partyhat, then author/verify all 21 anchors in neutral-pose numeric previews; no runtime guessing or 0.38/4.3 constants.
6. Instantiate `new Mesh()`, set `indexFormat=UInt32` iff max index >65535, else UInt16 **before** indices; assign `vertices`, `normals`, `tangents`, `uv`/`uv2`, `colors32` with the generated `Il2CppStructArray<T>` wrappers; use the shipped `SetUVs(channel, ...)` overload for any additional exported UV channels. Set `subMeshCount`; call `SetTriangles(Il2CppStructArray<int>, submesh, false)` per slot, then `RecalculateBounds()`. Preserve supplied normals/tangents; otherwise call `RecalculateNormals()` and, after UV0, `RecalculateTangents()`. Cache meshes; only `UploadMeshData(true)` after validation no longer needs CPU access.
7. Create `new Texture2D(w,h,TextureFormat.RGBA32,true,linear)`; `linear=false` for albedo/emission, true for normal/mask maps. `LoadRawTextureData(Il2CppStructArray<byte>)`, then `Apply(true,true)` to generate a new complete mip chain and release CPU pixels; do not submit compressed source blocks or pretend exported mip 0 includes all mips. Preserve wrap/filter; texture-orientation fixture must pass before any row flipping.
8. Use **URP/Lit**, cloning a known opaque game URP/Lit material template to retain working shader variants; `Shader.Find("Universal Render Pipeline/Lit")` + null/isSupported checks is the fallback, not Unlit as the final character material. Set `_BaseMap`, `_BaseColor`, `_Metallic` (default 0), `_Smoothness` (default 0.25), converted maps/keywords only after `HasProperty`. Source cutout/transparent slots use matching existing URP/Lit template states, including blending/ZWrite/queue; do not merely set `_Surface`. No hand-rolled shader compilation. Unlit is a diagnostic pink/black isolation test only.
9. Build root/child GameObjects; call `AddComponent(Il2CppType.Of<MeshFilter>()).TryCast<MeshFilter>()` and corresponding MeshRenderer, set `sharedMesh` and `sharedMaterials` (Il2CppReferenceArray<Material>). Add CosmeticTag first. Default `receiveShadows=true`, `shadowCastingMode=On`; camera-view hiding must not introduce a floating first-person hat shadow. Never instantiate materials each frame.
10. HAT: `root.transform.SetParent(model.Bones.Head,false)`; CHEST→semantic target `spine.003`, HIP→`Bones.Pelvis`, watch→semantic `forearm.R` (not wrist). Resolve from `Bones.AllBones` with uniqueness checks. These last three remain their proper slots; do not attach every prefab to Head. Preserve source descendant TRS under a separate target-fit root.
11. Fit in world metric units: desired uniform world scale `s=(targetAnatomyWidth/sourceAnatomyWidth)*FitScale`, where source width is measured in the same normalized prefab/socket coordinate units as exported geometry. Express target anchors in an unscaled, head-oriented metric frame; compute its fit translation `targetAnchor - s*fitRotation*sourceAnchor`, then convert the desired world position through `head.InverseTransformPoint`. Keep the baked placement below it, counting recorded root scale exactly once. For approximately uniform positive parent scale set fit-root localScale componentwise to `s / abs(parent.lossyScale)` and convert world rotation with parent inverse rotation. Log parent scale, s and fitted world bounds on bind.
12. If ancestor nonuniform scale plus rotation creates shear, reciprocal lossyScale is not an exact inverse: keep a rigid root parented to Head at identity and bake the required affine compensation into a per-model mesh copy for each renderer (`meshCorrection=inverse(renderer.localToWorldMatrix)*MdesiredWorldRenderer`, including its preserved child TRS), with inverse-transpose normals and corrected winding for negative determinants. Cache by parent linear stretch/shear and fit record; recompute only when these change, not on mere world translation/rigid rotation; reject singular matrices. Validate actual transformed width against target width within 2%, not just the localScale value.

## Cosmetics: mirror/screen visibility and cache ownership
- `MirrorPlayerVisibility.cs`: add one `IsCosmetic(Renderer)` marker predicate and use it when building `bodyPointers`, in `Snapshot()` itself (covers body scan AND cached-controller paths), and when deciding renderer/LOD ownership. Never snapshot, relayer, select, enable, restore or otherwise drive marked renderers. Preserve the mirror's existing native-key suppression and noncosmetic restoration unchanged. Marker ancestry may be checked defensively, but every renderer carries its own marker.
- Do not rely on `SimpleRenderingController.EnsureCachedRenderers()` discovering new hats, and do not append hats to native renderer caches: those caches may predate attachment or later be rebuilt. Cosmetics owns a complete renderer list and explicitly sets enabled/forceRenderingOff per view after native LateUpdates. Respect foreign body-hide reasons (death/cutscene/equipment), not the body renderer.enabled value that the mirror deliberately overrides. Expose a read-only `HasForeignHide` query from MirrorPlayerVisibility for its bound controllers; when unbound, evaluate native rendering-disable reasons plus POV, with unknown visibility failing hidden.
- Put cosmetic renderer GameObjects on existing `TV_PlayerModelMesh` layer 23, **not** the selected mirror-only body layer, 24 or 15. That layer has the game's third-person URP rendering support. Screen visibility does not imply culling-mask inclusion: snapshot relevant owner world-camera masks, OR `1<<23` only where necessary, and restore only owned bit changes on teardown. Do not edit UI/arms cameras or broad scene masks.
- `Mirror.cs`: explicitly OR `1<<23` into each mirror camera mask and pass a cosmetics view scope around `reflectCam.Render()` in `MirrorRuntime.Tick()`. This is additional to the MirrorPlayerVisibility marker exclusion; exclusion alone does NOT establish mirror pixels. Register mirrors by camera pointer, not by name, and retain current exclusions of layers 24/5/15.
- Cosmetics code: default screen state is `equipped && alive && bodyActive && !foreignHide && thirdPersonPOV`; unknown POV is hidden. Read current POV on bind and track local `PlayerModelDisplayer.OnEnableFirstPersonViewModeInternal/OnEnableThirdPersonViewModeInternal` callbacks. Never derive POV from body.enabled, and never deactivate the cosmetic root merely for first person (that would also hide it from the mirror).
- `BeginMirrorView(camera)` snapshots each cosmetic renderer.enabled/forceRenderingOff/shadow state on a stack, temporarily enables eligible cosmetics regardless of first-person POV, and returns a disposable scope restoring exact screen state in `finally` around Render. Mirror eligibility remains `equipped && alive && bodyActive && !foreignHide`; mirror ShowLocalPlayer=false may intentionally hide local accessories with the local body. Mirror baseline with ShowLocalPlayer=true must include hats.
- Before normal screen rendering, reassert the screen policy after native cache mutations; first person disables hats and their shadows, third person enables them. Explicit mirror scope works even though this mirror's camera renders manually inside the post-animation callback; do not wait for a later SRP event to make it visible. Handle nested mirror scopes/Render exceptions without leaking enabled hats into first person.
- Equip changes increment a local renderer-set generation; update marker/renderer registry before parenting, destroy removed instances only outside a render scope, then rebind mirror classification if a previous generation had snapshotted that object. Do not depend on a future mirror Rebind to discover cosmetics. Model swap/respawn/hot unload removes instances, view scopes, hooks and mask ownership before destroying shared caches.
- Selection is our own OnGUI panel opened by F7: scroll all 21 ids/icons, checkbox per id, clear-all and close. Persist a sorted deduplicated CSV through `SetCosmeticsEquipped`; parse only known ids. Allow stacking as MoreCompany does; no native wardrobe injection, networking or remote-player cosmetics.

## Failures: required log signatures and response
| Signature | Meaning and mandatory action |
|---|---|
| `PORT_PACK_INVALID entry=... reason=...` | Bad schema/checksum/size/indices; reject pack or affected independent asset before Unity allocation. |
| `EMOTE_HASH_UNRESOLVED clip=... hash=...` / `EMOTE_HASH_COLLISION` | Incomplete/wrong root candidates; fail that clip export, expand real hierarchy candidates, never guess names. |
| `EMOTE_STREAM_MISMATCH expected=... decoded=...` / `EMOTE_UNSUPPORTED_HUMANOID` | Decoder omitted packed/discrete channels or semantics; retain offending raw data and stop that clip. |
| `EMOTE_BIND_FAILED bone=... model=...` / `EMOTE_FIDELITY_LOSS` | Missing major bone stops model playback; missing fingers/unsupported nonroot channels get explicit per-clip loss report. |
| `EMOTE_OWNERSHIP_FAILED` / `EMOTE_LATE_WRITER bone=...` | Native evaluation not suspended or later transform writer; release our key and disable playback until ownership/order is fixed. |
| `EMOTE_STOP reason=... released=...` / `EMOTE_RESTORE_FAILED` | Log every stop once with model generation and key state; retry our release while object lives, never clear other owners' keys. |
| `COSMETIC_FIT_INVALID id=... scale=... widthError=...` | Singular/sheared/miscalibrated attachment; hide that item, fix fit/mesh compensation rather than copy LC's fudge. |
| `COSMETIC_SHADER_UNAVAILABLE` / `COSMETIC_MATERIAL_APPROX` | Missing lit template/variant blocks affected slot; approximated HDRP details are reported. Pink/black diagnostic uses Unlit only to isolate lighting/shader from mesh/UV errors. |
| `COSMETIC_VIEW_MISMATCH camera=... layer=... mask=... pov=... foreignHide=...` | Wrong mask, native cached hide or leaked mirror scope; log enabled/forceOff/bounds and compare screen+RT pixels; never exclude the item from mirrors to fix it. |

## Editor fallback: activate only on demonstrated data-level blocker
- Produce a reproducible failing clip/binding fixture plus decoder coverage proving missing semantics/reference data cannot be reconstructed; a motionless naïve hash remap, wrong playback ordering or unsupported SetCurve usage is not such proof. Continue other extractable assets; do not replace LC clips with native gestures.
- Use a **Unity 6000.3.16f1 Editor** for this fallback; **GUI license activation is available**. It buys Editor-only curve authoring/compilation (`AnimationUtility.SetEditorCurve(s)`), rig/Avatar evaluation and Windows64 bundle building, not automatic rig retargeting or guaranteed loading of every 2022 bundle. Import/load the 2022 source bundle in the Editor if compatible; extract clips/reference rig, evaluate and bake target-bound Generic transforms, then re-export 6000 clips in a target-platform bundle. If the old bundle is rejected, feed decoded interchange curves or recovered source `.anim`/rig through an appropriate 2022 extraction project and migrate the authoring assets; changing bundle headers is not conversion.
- Rebind paths/axes and bake in-place motion against Alterum's hierarchy before `BuildPipeline.BuildAssetBundles`; then play those compiled non-Legacy clips through the already-proven added Animancer layer with the same cancellation/ownership rules (do not use DisableAnimancerAndAnimator while graph playback is required). This is the literal compiled-clip alternative to the CPU adapter, not a different emote-content scope.
